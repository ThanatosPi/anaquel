# Código de Anaquel

Copia pública, sin historial, del repositorio del equipo.

- `app-android/` — app del dueño: Kotlin + Jetpack Compose (`./gradlew :mobile:assembleDebug`).
- `simulador/` — comercio sintético, escenarios y verificador del motor (`python verificar.py`).
- `base-de-datos/` — esquema PostgreSQL (21 tablas, 23 disparadores) y datos de prueba.

Sitio del proyecto: https://thanatospi.github.io/anaquel/
